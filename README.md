# borja-IT-110-Activity

## Run the Flutter app

The Flutter project is in the `semester_project` subfolder. Run Flutter commands
from that folder:

```powershell
cd .\semester_project
flutter pub get
flutter run -d chrome
```

Alternatively, from the repository root, pass the project directory explicitly:

```powershell
flutter run --project-dir .\semester_project -d chrome
```

To open the Flutter project directly in VS Code, run `code .\semester_project`.
